# Web Development Lab 5

## Overview
This is Lab 5 for ITMD-361. In this lab, I created a web form that allows users to input and submit their information. The goal of this lab was to understand how HTML forms work and how user input is structured and collected on a webpage.

## Features
- Created an HTML form for user input
- Included multiple input fields for collecting user information
- Followed structured lab instructions provided by the professor
- Practiced form layout and organization

## Tools Used
- HTML5
- Visual Studio Code
- GitHub (for version control and submission)

## Learning Outcomes
- Learned how to build and structure HTML forms
- Understood different input types and form elements
- Gained experience organizing user input fields
- Improved understanding of form-based web interactions

## Purpose
The purpose of this lab was to gain hands-on experience creating and structuring HTML forms and understanding how user input is collected in web development.
